# symfony-mail : mailbox de dev/recette et socle d'envoi

Sources : todo Sapiens (`.wex/journal/todo/sapiens-dev-mailbox-and-mail-foundation.md`), mailbox de session de `symfony-user-demo`, archéo network (`NETWORK/archeo/proposed-packages/symfony-mail`).

## Décisions (avec le owner)
- Pas de boîte de réception réelle : la mailbox sert au dev, à la recette et à la démo DS.
- Une seule mailbox, minimale, dans `symfony-mail-ds`, routée en dev et test seulement.
- Pas de mails stockés en base pour l'instant. Network sera reconstruit, pas archéologisé.
- Destinataire : `MailRecipientInterface` (le terme « Mailable » désigne le message dans l'écosystème) ; langue : `HasLocaleInterface`/`HasLocaleTrait` dans symfony-translations.
- Afficher le code de connexion directement : non (contournerait le second facteur). Lien vers la mailbox : oui.

## Fait
- `symfony-mail` :
  - transport `mailbox://` (refusé en prod), avec un `.eml` et un résumé `.json` par mail ;
  - `MailboxService` ;
  - commandes `mail:mailbox-last` et `mail:mailbox-purge` ;
  - `MailSenderService` (textes `@mail::`, layout, partie texte qui garde les URL, locale explicite, envoi au transport, aucun log) et `sendTo()` ;
  - fonction Twig `mailbox_url()` ;
  - 28 tests.
- `symfony-mail-ds` : page `/mailbox/`.
- `symfony-mail-demo` : page `/mail/` avec trois exemples. Les deux pages sont regroupées sous une seule entrée de menu « Mails » (`#[MenuItem('mail')]`).
- `symfony-translations` : `HasLocaleInterface` et `HasLocaleTrait`.
- `symfony-user` :
  - `AbstractUser` porte la colonne `locale` et implémente `MailRecipientInterface` ;
  - `RememberLocaleSubscriber`, optionnel ;
  - les mails passent par `MailSenderService` ;
  - lien vers la mailbox sur la page du second facteur et sur « mot de passe oublié » ;
  - 110 tests.
- `symfony-user-demo` : de vrais mails arrivent dans `/mailbox/`. La mailbox de session est supprimée, et le code TOTP est sur `/user/authenticator`.
- Apps :
  - design-system : installé, migration `locale`, `MAILER_DSN=mailbox://default`, expéditeur par défaut, menu ;
  - Sapiens : installé, migration `locale`, code local retiré, `access_control` sur `^/mailbox/` ;
  - app-board : installé, sans entité utilisateur, donc pas de migration.
